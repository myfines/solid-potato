# TIA V20 AI 助手：新手安装与使用说明

## 你需要准备什么

- Windows 电脑。
- 已安装 TIA Portal V20；如果没有，请先从 Siemens 官方入口安装。
- 一个可用的 DeepSeek API Key。
- 第一次使用时不要同时打开多个 TIA Portal 或多个本助手窗口。

## 第一次安装

1. 解压整个压缩包到一个固定位置，例如 `D:\TIA-V20-AI`。
2. 不要只解压或移动其中某个文件，必须保留整个文件夹结构。
3. 双击 `install-agent.cmd`。
4. 如果 Windows 第一次询问权限，点击“是”。这是安装 Openness 连接所需的登记步骤。
5. 安装完成后，双击 `TiaV20Agent.exe`。
6. 浏览器打开后，在右侧填写 DeepSeek API Key，点击“保存 API Key”。Key 只保存在本机配置中。
7. 默认先关闭“无限模式”。测试工程确认安全后，才可以打开“无限模式”。

## 第一次对话示例

在左侧输入：

```text
你写一个电机启停示例程序，带梯形图，创建新工程，离线编译，不要下载到真实 PLC。
```

助手会显示实时步骤。正常情况下会依次检查会话、创建工程、创建 PLC、创建标签、生成程序块、生成 LAD 并编译。

## 在哪里看成品

完成后看左侧最终回复中的“工程路径”和“备份路径”。普通 TIA 工程通常位于：

```text
工程目录\项目名\项目名.ap20
```

双击这个 `.ap20` 文件时，请在 TIA Portal 中选择“打开已有项目”或“项目 → 打开”，不要选择“打开参考项目”。

打开工程后，在左侧项目树中查看：

- 设备：S7-1200 CPU；
- PLC 变量：输入、输出和标签；
- 程序块：SCL 功能块、实例 DB 和 `Main [OB1]`；
- 打开 `Main [OB1]` 后可查看 LAD 网络。

## 权限和安全

- 未打开“无限模式”时，创建、修改、保存、编译、下载和上线操作会被拦截或要求确认。
- “无限模式”只建议用于专门的测试工程；不要对生产工程使用。
- 助手默认只进行离线操作，不会自动下载或上线，除非你明确提出并确认。
- 不要把 API Key 发到聊天、GitHub 或截图中。
- 不要删除已有 TIA 工程。新项目应使用独立目录并保留备份。

## 常见问题

### 页面打不开

确认 `TiaV20Agent.exe` 是从完整解压目录启动的，并检查 `http://127.0.0.1:8766/`。不要同时启动多个版本。

### 提示项目已打开

先关闭其他 TIA Portal 工程窗口，等待 TIA 完成保存。不要在“打开参考项目”菜单中打开普通 `.ap20` 工程。

### 提示需要写入权限

在右侧勾选“无限模式”，点击“保存模式”，然后重新发送任务。已经被拦截的任务不会自动继续。

### 提示目录不存在

使用绝对路径，例如 `E:\TIA_Test\projects`。助手会创建缺失目录；如果路径位于安装目录内，会自动改用工程目录外的备份目录。

### 任务停止或 MCP 断线

先等待当前错误显示完成，再重新提交任务。助手会自动重连一次；仍失败时，请关闭其他测试代理和未保存的 TIA 工程，再重试。

### 如何停止任务

点击右侧“停止”。停止后会取消当前 MCP 调用，完成后才可以开始下一项任务。

### 如何清理测试进程

使用“一键清理测试进程”。它只清理本项目安装包启动的测试代理，不会清理 `E:\simense` 下的用户程序。清理隐藏 TIA 实例前，必须确认没有未保存工程。

## 重要限制

- 目前只针对 TIA Portal V20 验证。
- 标准 PLCSIM 的自动连接依赖本机安装和配置，未找到虚拟接口时助手会停止并说明原因。
- 没有连接真实 PLC 时，只能验证工程生成和离线编译，不能证明真实下载或现场运行。
